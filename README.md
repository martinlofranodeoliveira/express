# Exemplo de servidor HTTP com Express

Exercício de servidor Express com arquivos HTML/CSS. Não confundir este repositório de estudo com o framework oficial Express.

**Estado:** projeto educacional/legado; avalie código e dependências antes de iniciar.

## Começar em português

**Requisitos:** Node.js e npm.

```sh
git clone https://github.com/martinlofranodeoliveira/express.git
cd express
npm ci --ignore-scripts
# Revise app.js e a porta/endereço de escuta antes de executar node app.js.
```

Use um ambiente de desenvolvimento separado. Não envie `.env`, chaves, bancos,
uploads ou dados pessoais ao Git. Nas demonstrações, use somente dados fictícios.
